# svitlyk-devices.github.io

Сайт Світлика: одна статична сторінка `index.html` (HTML, CSS і трохи JS в одному файлі, без збирання).

Адреса: https://svitlyk-devices.github.io

## Оновлення

Змінити `index.html`, закомітити й запушити в `main`: GitHub Pages публікує за хвилину-дві.
Налаштування Pages: Settings → Pages → Deploy from a branch → `main`, `/ (root)`.

## Що налаштувати

- `TELEGRAM_LINK` у кінці `index.html`: куди веде кнопка «Написати в Telegram» (заявки на бету).
- `.nojekyll`: Pages віддає файли як є, без обробки Jekyll.

## Правила

- GitHub Pages не можна використовувати для продажів. Коли з'являться ціни й замовлення, сайт переносимо на власний хостинг (FTP/cPanel) або прив'язуємо домен до іншого хостингу.
- Логотипи Matter і «Works with Apple Home» не використовуємо без сертифікації, лише текст.
- Обіцянки на сторінці мають відповідати прошивці (svitlyk-devices/svitlo-mini): сумісні інвертори, що перевірено, а що ні.
